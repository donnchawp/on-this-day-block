Display your historical blog posts from the same calendar day in previous years using a beautiful carousel block.

== Description ==

The On This Day Block is a Gutenberg block that automatically showcases your blog's posts from the same calendar day in previous years. It's a great way to resurface your historical content and show your readers what you were writing about in the past.

Features:

* Carousel display of historical posts
* Thumbnail images from featured images or first post image
* Year indicators for each post
* Navigation arrows for easy browsing
* Responsive design
* Customizable alignment and spacing
* Support for custom CSS classes

== Installation ==

1. Upload the plugin files to the `/wp-content/plugins/on-this-day-block` directory, or install the plugin through the WordPress plugins screen directly.
2. Activate the plugin through the 'Plugins' screen in WordPress
3. Use the block editor to add the 'On This Day' block to any post or page

== Frequently Asked Questions ==

= How does the plugin choose which posts to display? =

The plugin displays posts from your blog that were published on the same month and day as today, excluding posts from the current year.

= Can I customize the appearance of the block? =

Yes, the block supports WordPress's built-in alignment and spacing controls. You can also add custom CSS classes for additional styling.

= Does it work with any theme? =

Yes, the block is designed to work with any WordPress theme that supports the block editor.
